# Графит — лендинг MacBook 2026

Одностраничный сайт магазина MacBook: интерактивная 3D-презентация, вся линейка 2026 года,
сравнение моделей, цены и форма заявки с отправкой в Telegram.

**Демо:** https://grafit-macbook-2026.netlify.app

**Стек:** Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · framer-motion ·
three.js + React Three Fiber · zod

## Возможности

### Первый экран: 3D MacBook, который открывается при прокрутке
- Реальная 3D-модель MacBook Pro 16″ (glTF, ~1 МБ, хранится в проекте: `public/models/`).
- При загрузке ноутбук закрыт; с прокруткой крышка плавно поднимается на петле, ноутбук
  разворачивается к зрителю и приближается.
- Когда крышка почти открыта, экран загорается и на нём от руки пишется «hello».
- Крышка не привязана к колесу напрямую, а плавно «догоняет» прокрутку (демпфер с ограничением
  скорости): при спокойной прокрутке следует за пальцем, при резком рывке всё равно открывается
  не быстрее ~1,2 с — анимацию видно целиком.
- Блок закреплён на экране (sticky), пока идёт анимация, затем страница прокручивается дальше.
- Без WebGL2 или при системной настройке «уменьшить движение» показывается статичное фото.

### Разделы страницы
- **Почему MacBook** — преимущества в трёх группах (чип, экран, каждый день); при наведении
  на пункт справа появляется пояснение.
- **Линейка 2026** — MacBook Neo, Air 13 и 15 (M5), Pro 14 (M6), Pro 16 (M5 Pro / Max):
  реальное фото, описание, ключевые цифры, цена «от», кнопки «Заказать» и «Сравнить».
- **Сравнение моделей** — выбор любых двух моделей и таблица из 14 характеристик; строки
  с различиями выделены. Ссылка «Сравнить» у модели сразу подставляет её в сравнение.
- **Цены** — все конфигурации по моделям.
- **Заявка** — форма (имя, почта, ник в Telegram, комментарий) и прямая ссылка на Telegram.

### Анимации
- Каждый раздел въезжает снизу с наклоном и выпрямляется — тот же эффект, что у экрана ноутбука.
- Фотографии выезжают из-за левого и правого края экрана, текст появляется по очереди.
- Все движения отключаются при «уменьшить движение» в настройках системы.

### Форма заявки и безопасность
- Проверка полей в браузере и повторно на сервере (общая схема zod, `lib/contact-schema.ts`),
  понятные сообщения об ошибках у каждого поля.
- Сервер (`app/api/contact/route.ts`) принимает только JSON со своего сайта (проверка Origin),
  тело до 4 КБ, ловушка для ботов, не больше 5 заявок за 10 минут с одного IP.
- Заявка уходит в Telegram-бот обычным текстом, без разметки; токен проверяется по формату.
- Заголовки безопасности в `next.config.ts`: CSP, X-Frame-Options, HSTS, Referrer-Policy,
  Permissions-Policy, nosniff.

### Производительность
- 3D-сцена рисует кадры только пока что-то движется (`frameloop="demand"`); в покое и вне
  первого экрана — ноль кадров и нулевая нагрузка.
- Экран «hello» перерисовывается только во время написания слова.
- На слабых устройствах (≤ 4 ядер, ≤ 4 ГБ памяти или режим экономии трафика) 3D рисуется
  в обычном разрешении без сглаживания, наклон разделов отключён.
- 3D-библиотеки грузятся отдельным чанком; основной JS страницы ~180 КБ.
- Фото сжаты и уже переведены в оттенки серого (без CSS-фильтров).

## Запуск

```bash
npm install
npm run dev                       # http://localhost:3000
npm run build && npm run start    # production
```

Нужен Node.js 20 или новее.

## Заявки в Telegram

1. Создайте бота у @BotFather и получите токен.
2. Узнайте id чата, куда слать заявки (например, через @userinfobot).
3. Скопируйте `.env.example` в `.env.local` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
   На Netlify те же переменные задаются в Project configuration → Environment variables.

Без этих переменных в dev-режиме заявка только пишется в консоль, а в production форма отвечает
ошибкой и предлагает написать в Telegram.

## Деплой на Netlify

В проекте есть `netlify.toml`; Netlify сам подключает рантайм Next.js, `/api/contact` работает
как серверная функция.

```bash
npx netlify-cli deploy --build --prod
```

## Что заменить перед запуском

- `lib/models.ts` — цены (сейчас образец), название `site.name`, ник `site.telegram`, телефон и город.
- Фото моделей Air и Pro — снимки предыдущего поколения (корпус тот же), под ними есть подпись.

## Структура

- `app/` — страница, общий макет, стили (`globals.css`), API заявок.
- `components/site/` — секции страницы: `hero.tsx` и `hero-macbook.tsx` (3D-сцена),
  `hello-screen.ts` (экран «hello»), `features`, `models`, `compare`, `pricing`, `contact`,
  `footer`, `scroll-panel.tsx` (эффект наклона), `reveal-observer.tsx` (появление элементов).
- `components/ui/` — компоненты shadcn; `container-scroll-animation.tsx` — прежний вариант
  первого экрана, сейчас не используется.
- `lib/models.ts` — модели, характеристики, цены; `lib/contact-schema.ts` — проверка формы.
- `public/models/` — 3D-модель, `public/img/` — фотографии.
